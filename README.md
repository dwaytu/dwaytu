I'm **Dwight Karl B. Gaga-a**, a BS Information Systems student at **STI College Tagum**, Philippines. My work focuses on turning operational requirements into usable applications, from interface design and API development to database workflows and deployment.

My main project is **SENTINEL**, an integrated security operations platform developed as a capstone project for Davao Security & Investigation Agency (DASIA).

## Featured project — SENTINEL

SENTINEL brings personnel coordination, asset accountability, and field operations into one platform, with clients for **Web, Desktop, and Android**.

- **Access and approvals:** account verification, authentication, and governed user management.
- **Personnel operations:** scheduling, attendance, daily time records, and guard replacement.
- **Asset accountability:** firearms, permits, armored vehicles, trips, and maintenance.
- **Field coordination:** incident reporting, service requests, notifications, and monitoring.
- **Analytics and traceability:** operational reports, performance views, and audit logs.
