## 🛡️ Featured project · SENTINEL

> **One platform for personnel coordination, asset accountability, and field operations.**

SENTINEL is a capstone project developed for **Davao Security & Investigation Agency (DASIA)**, with clients for **Web, Desktop, and Android**.

### ✨ What it brings together

| | Capability | What it supports |
| :---: | :--- | :--- |
| 🔐 | **Access & approvals** | Account verification, authentication, and governed user management |
| 👥 | **Personnel operations** | Scheduling, attendance, daily time records, and guard replacement |
| 🗂️ | **Asset accountability** | Firearms, permits, armored vehicles, trips, and maintenance |
| 🚨 | **Field coordination** | Incident reporting, service requests, notifications, and monitoring |
| 📊 | **Analytics & traceability** | Operational reports, performance views, and audit logs |
